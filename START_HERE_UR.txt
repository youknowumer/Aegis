AEGIS + LOCAL LANGUAGE VOICES (MMS): START HERE
================================================

Ye zip poora Aegis hai. Jis language mein aap baat karen, Aegis usi language ki apni awaaz mein jawab deta hai
(Urdu, Roman Urdu, Hindi, Arabic, English, Spanish, French, German, Korean aur 20+ aur).

3 STEPS (Windows)
1. install-voices.bat par double click. (Python 3.10+ chahiye. Internet sirf ek baar, lagbhag 5 GB.)
   Kuch hi languages chahiye to Command Prompt mein:  install-voices.bat --langs ur,en,hi,roman
2. start-local.bat par double click.
3. Browser mein http://localhost:8000/app.html kholen. Settings > Voice mein likha hoga:
   "Local language voices are on (N languages)".

Mac / Linux: ./install-voices.sh phir ./start-local.sh
Docker:      docker compose build --build-arg WITH_MMS=1  (phir SETUP.md dekhein)

KHAAS BAATEN
- Italian, Chinese, Japanese, Czech ke MMS models hain hi nahi: inke liye purani Edge awaaz chalti hai.
  Jo language download nahi ki, wo bhi Edge par chali jati hai, Aegis chup nahi hota.
- Har language ka ek fixed speaker hai (kisi ka mard, kisi ka aurat). Jazbaat speed aur loudness se aate hain.
- License: MMS models CC-BY-NC 4.0 hain, yaani sirf NON-COMMERCIAL. Paise charge karne se pehle
  AEGIS_MMS=0 karein aur OpenAI / ElevenLabs key lagayein.
- Har language ~150 MB RAM leti hai. 2 GB+ RAM wali machine chahiye (Render ka free tier chhota hai).
- Pehle se download kiye hue MMS models hain? AEGIS_MMS_DIR ko unke "models" folder par point karein.
- Roman Urdu ka model standard spelling par train hua hai. Pasand na aaye to AEGIS_MMS_ROMAN=0.
- Is zip mein models shamil nahi (5 GB): install-voices.bat unhe aapke PC par download karta hai.

Poori tafseel: SETUP.md ("Local language voices"), SCALING.md, CHANGES-v16.md
Status dekhne ke liye (server folder mein):  python scripts/mms_download.py --status


==================== v17: NAYA (Roman Urdu) ====================
1) Web voice control: folder "extension" ko Chrome/Edge mein load karein
   (chrome://extensions > Developer mode > Load unpacked > extension folder).
   Phir Aegis > Settings > Browser control > "Copy connection code" > extension ke popup mein paste > Connect.
   Ab bolein: "Hey Aegis, YouTube kholo aur Kesariya chalao", "ye page padho", "neeche scroll karo".
   Password Aegis kabhi nahi likhta; kharidna/bhejna/delete karna pehle aap se poochta hai.
2) Aegis page par foran voice commands: "show numbers", "click 3", "click settings", "zoom in", "type hello", "press enter".
3) Emotions: ab Aegis samajhta hai aap ko kya chahiye (sunna, hal, tasalli, khushi mein shirkat) aur "theek hoon" ke peechay chhupa dukh bhi.
4) Memory: "yeh kabhi na bhoolna" bolein to pin ho jati hai. Memory export/import, logon ki yaadein, aur mood ke rhythms (jaise Sunday ko udaasi).
Details: CHANGES-v17.md


==================== v20: NAYA (Roman Urdu) ====================
1) Naye voices (Piper): halke, tez, zyada natural. install-voices.bat (ya ./install-voices.sh) ab pehle Piper (lagbhag 1 GB) phir MMS install karta hai.
   Sirf Piper:  install-voices.bat --piper-only      Behtar quality:  install-voices.bat --high
   Har sentence: pehle us language ki Piper awaaz, phir MMS, phir Edge. Urdu/Punjabi/Tamil jaisi languages MMS par chalti hain, koi language kam nahi hui.
   Status:  python scripts/piper_download.py --status   (server folder mein)
2) Observability: AEGIS_ADMIN_TOKEN set karein, phir http://localhost:8000/admin/voice kholen: kaunsa engine bola, har language ke requests/errors,
   latency p50/p95/p99, fallbacks, queue, downloads, memory. Prometheus ke liye /metrics. JSON logs ke liye AEGIS_LOG_JSON=1.
Details: CHANGES-v20.md, SETUP.md ("Piper voices", "Observability"), SCALING.md



==================== v21: NAYA (Roman Urdu) ====================
1) Awaaz ab sunne wale ke ilaqe ke hisab se: Settings > Voice > "Voice region" (Auto ya apna mulk chunein).
   Pakistan / India ke liye English Indian accent mein, UK ke liye British, Misr ke liye Misri Arabic, Mexico ke liye Mexican Spanish, waghera.
   Aap jo zuban bolte hain wo bhi awaaz ke saath jaati hai, taake naam aur angrezi lafz aap ki tarah bolay jayen.
2) Urdu ab pehle neural awaaz (Uzma) mein bolti hai; internet na ho to local MMS awaaz. Purana tareeqa (pehle local):  AEGIS_TTS_EDGE_FIRST=0
   Urdu jawab ka lehja bhi behtar: rozmarra Pakistani Urdu, ۔ ؟ ، se saans ki jagah, aur Roman Urdu ki ek hi spelling.
3) Real-time baat-cheet (naya talk.js):
   - Jawab likha ja raha hota hai to Aegis pehla jumla pura hote hi bolna shuru kar deti hai (Settings > Voice > "Start speaking while I am still writing the answer").
   - Voice mode mein beech mein bol kar Aegis ko rok sakte hain. Headphones lagay hon to khud on; open speakers par default band (warna wo apni awaaz sun kar ruk jati hai). Settings > Voice > "Let me interrupt by talking".
4) Server ke 404 bug theek: auth-ui.js aur auth-ui.css ab serve hotay hain.
Details: CHANGES-v21.md
