# Hero icons

The landing hero loads four glossy 3D icons from this folder: `message.webp`, `browse.webp`, `transact.webp`, `web.webp`
(320x320, transparent). Until they are here, the page falls back to the CDN copies. Run `scripts/fetch-vela-icons.sh` once
to download them, so the site is fully self-hosted (and the colour tint works without any CORS dependency).
