Before you install

  • Windows 10 or 11, 64-bit.
  • Internet for the AI, voice and live data.
  • An AI key: Groq has a free tier, or use Claude, OpenAI or Gemini.
  • Python is not needed. It is bundled.

Install in five steps

  1. Run Aegis-Setup.exe and choose a folder.
  2. Open Aegis. It starts its own server on this PC only.
  3. Create an account. It is stored locally.
  4. Open Settings > AI provider, paste the key, press Test, then Save.
  5. Say “Hey Aegis” and talk.

Can Aegis delete my files without me knowing?

No. Writing, moving, deleting, typing and shell commands all show an Allow or Deny prompt first. If you decline, or do not answer, Aegis does not retry that action.

Which parts of my computer can it reach?

File tools only work inside Documents, Desktop and Downloads. Outside those folders the request is refused, including attempts through shortcuts.

Does it work on Mac or Linux?

The web app works in any browser. PC control, meaning opening apps, typing and key presses, is Windows-only for now.

Windows says “Unknown publisher”. Is the installer safe?

The installer is not signed with a publisher certificate yet, which is why SmartScreen warns on the first run. Download it only from this page or the official GitHub Releases page, then choose More info and Run anyway.

How does the Windows app update?

It checks for a new version every 4 hours, downloads it in the background and offers Restart now or Later. Your account, memory and settings are kept.

What does it remember about me?

Only facts you share or ask it to save. They appear in the memory panel, and you can delete any of them at any time.

Can I talk to it instead of typing?

Yes. Turn on voice mode, say “Hey Aegis” and speak your request. Aegis reads the answer back to you, and you can switch it off at any time.

What do I need for voice and meeting notes?

A free Groq key for fast Whisper transcription, added in Settings. Without it, voice falls back to your browser’s own speech recognition. Meeting notes need the key, and your audio is sent only to the service you choose.
