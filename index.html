It only acts alone where it cannot hurt you

Every tool is sorted by risk. Reading and opening happen straight away. Anything that changes or removes something stops and waits for you.

Runs without asking

  • Open an app or a website
  • Search the web
  • List and read files
  • Take a screenshot
  • Check PC health
  • Remember a fact

Always waits for your Allow

  • Write, move or delete a file
  • Sort a whole folder
  • Type text into a window
  • Press keyboard shortcuts
  • Run a shell command
  • Forget a memory
  • Three folders only. File tools cannot leave Documents, Desktop and Downloads, even through shortcuts or symlinks.
  • No key on your PC. The AI key stays on the server. The desktop app never sees it.
  • Silence means no. If you do not answer an approval within a minute, the action is cancelled.
  • Hashed passwords. Passwords are stored with scrypt, and repeated sign-in attempts are throttled.

Questions people ask first

Can Aegis delete my files without me knowing?

No. Writing, moving, deleting, typing and shell commands all show an Allow or Deny prompt first. If you decline, or do not answer, Aegis does not retry that action.

Which parts of my computer can it reach?

File tools only work inside Documents, Desktop and Downloads. Outside those folders the request is refused, including attempts through shortcuts.

Does it work on Mac or Linux?

The web app works in any browser. PC control, meaning opening apps, typing and key presses, is Windows-only for now.

What does it remember about me?

Only facts you share or ask it to save. They appear in the memory panel, and you can delete any of them at any time.

Which languages can I use?

English, Urdu and Hindi for voice and text. Aegis answers in the language you write in.
